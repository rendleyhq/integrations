# Rendley connector for Power Platform

**AI video editing and generation for Power Automate, Power Apps, Logic Apps and Copilot Studio: prompt-to-video with the Rendley AI agent, text to speech, transcription, AI dubbing, lip sync, image, video and music generation, media uploads and MP4 rendering.**

A custom connector definition for the Microsoft Power Platform. Files:

- `apiDefinition.swagger.json`: the OpenAPI 2.0 definition with the `x-ms-*` extensions Microsoft requires, generated by `scripts/generate-swagger.cjs` (edit the script, not the JSON).
- `apiProperties.json`: the API key connection parameter and a `setheader` policy that adds the `Bearer` prefix, so users paste only the key.
- `icon.png`: 230×230 connector icon on the brand background (`iconBrandColor` #0C0C0C).
- `intro.md`: the intro document Microsoft asks for in a certification submission.
- `test/`: offline checks of the certification rules and a live harness that runs every operation.

## Operations

| Operation | What it does |
| --- | --- |
| Edit video with AI agent, Get agent job, Cancel agent job | AI agent edits of a project. |
| Run AI action, Estimate AI action cost | Any of 13 AI actions; file inputs go in `params.media`. |
| Render video, Estimate render cost, Get job, Cancel job | MP4 rendering and job follow-up. |
| Upload media from URL, Get media download URL | Media library. |
| List workspaces, List projects, Create project, Get project, Delete project | Projects, with dynamic dropdowns. |
| List voices, List dubbing languages | Catalog lookups. |

Rendley sends no webhooks and jobs are asynchronous, so a flow runs an action, then a **Do until** loop with **Delay** and **Get job** until `status` is `completed`, and reads `output.url`. Download URLs are signed and expire after a few hours.

## Testing

```bash
npm install
npm test                                 # regenerates the swagger, validates OpenAPI 2.0 and the certification rules
RENDLEY_API_KEY=... npm run test:live    # builds every request from the definition and runs all 18 operations
```

`paconn validate` needs a Power Platform login; run it from a signed-in machine before submitting:

```bash
pip install paconn && paconn login && paconn validate --api-def apiDefinition.swagger.json
```
